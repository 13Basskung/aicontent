## 🔴 ปัญหาที่ 1: Agent ไม่เปิด Browser

### 📅 วันที่พบ: 5 กุมภาพันธ์ 2026

### 🔍 อาการ
- กดปุ่ม "เริ่ม Auto-run" แล้ว Agent ไม่เปิด Browser
- Log ไม่แสดงข้อมูลการทำงาน
- Scheduler ทำงานได้ แต่ไม่มีการ launch browser

### 🎯 สาเหตุที่แท้จริง

#### สาเหตุหลัก: `PROFILES_DIR` ไม่ได้ใช้ Lazy Initialization

**Code ที่มีปัญหา:**
```javascript
// ❌ ใช้ PROFILES_DIR โดยตรง - อาจยังไม่พร้อมตอน module load
const PROFILES_DIR = path.join(app.getPath('userData'), 'browser-profiles');
```

**Code ที่ถูกต้อง (v1.6.65):**
```javascript
// ✅ ใช้ lazy initialization - รอจนกว่า app พร้อม
let PROFILES_DIR = null;

function getProfilesDir() {
  if (!PROFILES_DIR) {
    PROFILES_DIR = path.join(app.getPath('userData'), 'browser-profiles');
    console.log(`📁 Browser profiles directory: ${PROFILES_DIR}`);
    
    if (!fs.existsSync(PROFILES_DIR)) {
      fs.mkdirSync(PROFILES_DIR, { recursive: true });
    }
  }
  return PROFILES_DIR;
}
```

#### สาเหตุรอง: `instanceId` เปลี่ยนทุกครั้ง

**Code ที่มีปัญหา:**
```javascript
// ❌ instanceId เปลี่ยนทุกครั้ง - ทำให้สร้าง profile ใหม่ตลอด
instanceId = `scheduler-${slot.projectId}-${Date.now()}`;
```

**Code ที่ถูกต้อง (v1.6.65):**
```javascript
// ✅ instanceId คงที่ - ใช้ profile เดิมได้
const instanceId = `scheduler-${slot.projectId}`;
```

## 🔴 ปัญหาที่ 2: Browser เปิด URL ผิด (ไม่ใช่ startUrl ที่ตั้งไว้)

### 📅 วันที่พบ: ก่อน v1.6.65

### 🔍 อาการ
- Browser เปิดขึ้นมาแล้ว แต่ไปหน้าเก่าที่เคยเปิดไว้
- ไม่ได้ไปที่ `startUrl` ที่กำหนดใน Block

### 🎯 สาเหตุ
Playwright Persistent Context จำ URL ล่าสุดที่เปิดไว้ เมื่อเปิดใหม่จะกลับไปหน้าเดิม

### ✅ วิธีแก้ไข

เพิ่มการ navigate ไป `about:blank` ก่อน ใน `launchInstance`:

```javascript
// ✅ FIX: Clear old URL from restored session
try {
  await page.goto('about:blank', { waitUntil: 'domcontentloaded', timeout: 5000 });
  console.log(`🧹 Cleared old session URL - now on about:blank`);
} catch (e) {
  console.warn(`⚠️ Could not clear old URL: ${e.message}`);
}
```

### 📁 ไฟล์ที่แก้ไข
- `electron/playwright-bridge.js` - เพิ่ม `page.goto('about:blank')` ใน `launchInstance`

## 🔴 ปัญหาที่ 3: Auto-start Scheduler ไม่ทำงานหลัง Update

### 📅 วันที่พบ: ก่อน v1.6.69

### 🔍 อาการ
- หลังจาก update app ใหม่ Scheduler หยุดทำงาน
- ต้องกดปุ่ม "เริ่ม Auto-run" ใหม่ทุกครั้ง

### 🎯 สาเหตุ
- ไม่มีการบันทึก state ของ Scheduler ก่อน update
- ไม่มีการ auto-start Scheduler หลัง update

### ✅ วิธีแก้ไข

1. **บันทึก state เมื่อ start scheduler** ใน `scheduler.js`:
```javascript
function startScheduler(userId, instances) {
  // ✅ FIX: Save scheduler state to persist across updates
  store.set('schedulerState', { running: true, userId, timestamp: Date.now() });
  console.log('💾 Scheduler state saved to electron-store');
  // ...
}
```

2. **เพิ่ม `getSavedSchedulerState` function**:
```javascript
function getSavedSchedulerState() {
  return store.get('schedulerState', { running: false });
}
```

3. **Auto-start ใน `main.js`**:
```javascript
setTimeout(() => {
  const savedState = getSavedSchedulerState();
  if (savedState && savedState.running && savedState.userId) {
    console.log('🔄 Auto-restarting scheduler (was running before update)');
    startScheduler(savedState.userId, []);
    if (mainWindow) {
      mainWindow.webContents.send('scheduler:auto-started', { userId: savedState.userId });
    }
  }
}, 3000);
```

### 📁 ไฟล์ที่แก้ไข
- `electron/scheduler.js` - เพิ่ม `store.set`, `getSavedSchedulerState`
- `electron/main.js` - เพิ่ม auto-start logic
- `electron/preload.js` - เพิ่ม `onAutoStarted` listener
- `src/components/SchedulerPanel.jsx` - เพิ่ม `onAutoStarted` listener

## 🔴 ปัญหาที่ 4: หน้า Record - หน้าจอไม่เต็ม + ไม่บันทึก Login

### 📅 วันที่พบ: 6 กุมภาพันธ์ 2026

### 🔍 อาการ
1. **หน้าจอไม่เต็ม** - Browser ที่เปิดจากหน้า Record มีขนาด 1280x800 ไม่ใช่เต็มจอ
2. **ไม่บันทึก Login** - ล็อกอินแล้ว ครั้งต่อไปต้องล็อกอินใหม่
3. **เลือก Instance แต่ไม่ใช้ Profile จริง** - เลือก Instance เฉยๆ ไม่ได้เชื่อมต่อกับ Profile

### 🎯 สาเหตุที่แท้จริง

#### สาเหตุที่ 1: Viewport ถูกล็อคไว้

**Code ที่มีปัญหา (recorder.js):**
```javascript
// ❌ ล็อคขนาด viewport ตายตัว
viewport: { width: 1280, height: 800 },
args: [
  '--disable-blink-features=AutomationControlled',
  '--no-sandbox'
]
```

**Code ที่ถูกต้อง:**
```javascript
// ✅ ใช้ขนาดจอจริง
viewport: null,
deviceScaleFactor: undefined,  // ⚠️ REQUIRED
args: [
  '--start-maximized',  // เปิดเต็มจอ
  '--disable-blink-features=AutomationControlled',
  '--disable-infobars',
  '--no-first-run',
  '--no-default-browser-check',
  '--no-sandbox'
],
ignoreDefaultArgs: ['--enable-automation']
```

#### สาเหตุที่ 2: Profile Path ผิด

**Code ที่มีปัญหา (RecorderPanel.jsx):**
```javascript
// ❌ ใช้ relative path - ไปอยู่ใน Program Files
const profilePath = `./profiles/${selectedInstance.id}`;
```

**Code ที่ถูกต้อง (recorder.js):**
```javascript
// ✅ ใช้ absolute path ใน AppData
const profilePath = path.join(getRecorderProfilesDir(), profileName || 'default');
```
